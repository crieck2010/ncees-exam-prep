# Schema Contract v1 (LOCKED — 2026-10-08)

This document is the legal-technical guarantee behind `schema/question-v1.json`.
It is enforced by `src/fs_quiz/contract.py` (stdlib-only), the golden fixture
at `tests/fixtures/bank-v1-golden.json`, and `tests/test_contract.py`.

## What "locked" means

From v1.0.0 onward, for the entire v1 line:

1. **No field is ever removed or renamed.** Every field documented in
   `docs/QUESTION_SCHEMA.md` keeps its name, type, and meaning.
2. **No validation rule is ever tightened** in a way that rejects a bank
   valid under v1.0.0. (Rules may only be *clarified*.)
3. **Additive changes are minor-version only** and must be optional for
   readers: a v1.0.0 consumer must still parse a v1.x bank correctly by
   ignoring unknown fields. (Writers should still set `additionalProperties`
   discipline per the JSON Schema file.)
4. **Any breaking change ships as schema v2**: `schema_version: 2`, a new
   `schema/question-v2.json`, a migration guide, and a minor engine release
   that can still *read* v1 (readers stay backward compatible for one major
   line).

## What the lock protects

- The Flutter app (Phase 2) parses banks with a fixed model class. The lock
  means the app never needs a parsing migration inside the v1 line.
- Cached/shipped bank JSON files (app bundles, CDN) stay valid indefinitely.
- `QuizEngine.import_bank` fails *loudly* on contract violation instead of
  silently misgrading — a wrong answer key is worse than no quiz.

## How the lock is tested

- `tests/fixtures/bank-v1-golden.json`: 96 questions generated by v1.0.0,
  committed to the repo. `test_contract.py` asserts the current engine
  imports it and re-exports it **byte-identical**. Any change that alters
  generation output, field names, or validation breaks this test on purpose.
- `test_contract.py::test_fuzz_generation`: 48 topics × 15 seeds generate
  cleanly with globally unique qids and valid choices — the "infinite bank"
  claim, proven.
- `test_contract.py::test_flutter_contract_shape`: the documented
  `flutter_contract()` shape cannot drift silently.

## Changing the contract

To propose a v2: open an issue, draft `schema/question-v2.json`, write the
migration guide, and add a v1→v2 reader. Do not edit v1 files in place.
